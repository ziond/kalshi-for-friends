# Kalshi for Friends

A community prediction MVP using demo points.

## Current stage

Backend skeleton and PostgreSQL migration files. No API endpoints, business logic,
database connection, or frontend have been implemented. Nothing starts listening
when the empty server entry point is run. Migrations have not been applied to a
shared database.

See [backend/README.md](backend/README.md) for the layout and team boundaries.
See [database schema](backend/docs/database.md) for the database implementation handoff.
